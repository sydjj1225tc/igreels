# igreels

**[Open the live Reels demo](https://sydjj1225tc.github.io/igreels/)**

A student HTML/CSS/JavaScript prototype exploring scrolling and deliberate pauses in a Reels-style interface.

## Try it

Open `index.html` in a browser. Scroll through five Reel stills, then hold **Yes** for ten continuous seconds. Releasing early resets progress. Completing the hold opens a sixth Reel and a reminder; select **OK** to resume viewing. Keyboard users can hold Space or Enter on the button.

No build step, external services, or API keys are required. Images are stored in `assets/`.

## Design history

Earlier HTML versions, the initial stopping-cue sketch, and design notes are included. `initial-design-refined.html` matches the current demo.

## Scope

This is an educational prototype, not an Instagram product. Images are AI-generated stills; creator names, engagement counts, and audio labels are fictional. The fixed five-Reel threshold does not detect addiction or flow. The interface demonstrates a proposed intervention, not evidence of its effectiveness.
